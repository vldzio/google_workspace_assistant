Google Workspace Assistant

A Google ADK agent that decides which Workspace tools to call (calendar, Gmail, Drive) over the Model Context Protocol, then answers from what the tools return.

Simulated data. The real project connects to your own Google account through an OAuth-protected workspace-mcp server. This public demo uses the same agent code against a built-in mock MCP server with fictional sample mail, events and files. Nothing is read from or sent to a real account; each visitor gets their own private copy of the sample data.
